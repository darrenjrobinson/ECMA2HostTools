# Examples

This directory contains example scripts demonstrating how to use the ECMA2HostTools module.

## Available Examples

### Basic Service Management
See `ServiceManagement.ps1` for examples of starting, stopping, and monitoring the ECMA2Host service.

### Connector Operations
See `ConnectorOperations.ps1` for examples of working with connectors.

### Run Profile Automation
See `RunProfileAutomation.ps1` for examples of automating run profile execution.

## Usage

Each example script can be run independently:
```powershell
.\Examples\ServiceManagement.ps1
```

Make sure the ECMA2HostTools module is imported before running examples:
```powershell
Import-Module ECMA2HostTools
```
